## 1. Incident Summary

A Sales employee reported being unable to sign into a domain-joined Windows 11 workstation.

The user received the following Windows sign-in error:

> The referenced account is currently disabled and may not be logged on to.

Investigation in Active Directory Users and Computers (ADUC) identified that the employee's domain account was disabled.

After checking the employee's reported employment status with a department contact, the account was re-enabled through ADUC.

The simulated user subsequently confirmed successful sign-in.

**Root cause:** Disabled Active Directory user account.

**Resolution:** Re-enabled the user's account through Active Directory Users and Computers.

## 4. Investigation

### Step 1 — Identify the Affected Account

Opened Active Directory Users and Computers (ADUC) on the domain controller.

Located the account associated with:

```text
knguyen
```

The account displayed the disabled-account indicator in ADUC.

**Finding:** The domain account was disabled.

### Step 2 — Confirm Employment Status

Before restoring access, the technician contacted Rachel Brooks in the Sales department.

Rachel stated that Kevin remained an active employee, was not on leave, and was scheduled to work.

**Result:** Active employment status reported by department contact.

**Production consideration:** Departmental confirmation is not necessarily sufficient authorization. In a real organization, the technician should verify employment status and reactivation approval through HR or another authoritative process before enabling an account.

### Step 3 — Identify the Account State

The issue was a **disabled account**, not a password reset or account lockout.

These conditions require different administrative actions.

| Account Condition | Meaning | Typical Action |
|---|---|---|
| Disabled | Administrator or process has disabled the account | Investigate reason, obtain approval, enable if authorized |
| Locked out | Account locked due to authentication or security policy | Investigate failed attempts and unlock if authorized |
| Expired | Account has passed its configured expiration date | Verify employment and update expiration if authorized |
| Password expired | Password must be changed | Follow password-change or reset procedure |
| Incorrect password | Credentials are rejected | Verify identity and follow password troubleshooting procedures |

## 5. Root Cause

The `knguyen` Active Directory account had been disabled.

A disabled AD account cannot normally authenticate to domain resources.

**Root cause category:** Identity and account-state configuration.

**Lab context:** The disabled state was intentionally introduced as a reversible fault.

In production, the cause of the account disablement should be investigated before restoring access.

## 6. Remediation

### Action Performed in ADUC

1. Opened Active Directory Users and Computers.
2. Located Kevin Nguyen's account.
3. Confirmed the account was disabled.
4. Right-clicked the account.
5. Selected **Enable Account**.

**Result:** Account re-enabled through ADUC.

No password reset was performed.

### PowerShell Equivalent — Reference Only

```powershell
Enable-ADAccount -Identity knguyen
```

This is the PowerShell equivalent of enabling the account through ADUC.

**Note:** This command was not executed during the ticket. Remediation was performed using the GUI.

## 9. Useful Account Investigation Commands

### Check Enabled and Locked-Out State

```powershell
Get-ADUser -Identity knguyen -Properties Enabled, LockedOut |
    Select-Object SamAccountName, Enabled, LockedOut
```

### Inspect Common Account Properties

```powershell
Get-ADUser -Identity knguyen -Properties `
    Enabled, LockedOut, AccountExpirationDate, PasswordExpired, LastLogonDate |
    Select-Object `
    SamAccountName,
    Enabled,
    LockedOut,
    AccountExpirationDate,
    PasswordExpired,
    LastLogonDate
```

**Note:** `LastLogonDate` is derived from replicated logon information and may not reflect the user's exact most recent sign-in.

### Find Disabled Accounts

```powershell
Search-ADAccount -AccountDisabled -UsersOnly |
    Select-Object Name, SamAccountName
```

### Find Locked-Out Accounts

```powershell
Search-ADAccount -LockedOut -UsersOnly |
    Select-Object Name, SamAccountName
```

### Find Expired Accounts

```powershell
Search-ADAccount -AccountExpired -UsersOnly |
    Select-Object Name, SamAccountName
```

### Enable an Account

```powershell
Enable-ADAccount -Identity knguyen
```

### Unlock an Account

```powershell
Unlock-ADAccount -Identity knguyen
```

**Important:** `Enable-ADAccount` and `Unlock-ADAccount` perform different operations. Do not use them interchangeably.

## 11. Production Security Considerations

Re-enabling a disabled account can restore access to sensitive organizational resources.

Before enabling an account:

1. Verify the affected user's identity.
2. Determine why the account was disabled.
3. Confirm employment status through an authoritative source.
4. Obtain required approval for reactivation.
5. Check whether the account is subject to a security investigation.
6. Make the authorized change.
7. Verify access and document the action.

Do not automatically enable every disabled account simply because a user requests access.

## 12. Lessons Learned

### Active Directory

- A disabled account is different from a locked-out account.
- ADUC provides visual indicators for account states.
- Account reactivation may require HR or security approval.
- Password resets are unnecessary when the actual issue is account disablement.

### Troubleshooting

- Ask for the exact error message.
- Confirm which workstation and account are affected.
- Verify the user's employment status before restoring access.
- Apply the smallest necessary change.
- Request a new sign-in attempt after remediation.

### PowerShell

- `Get-ADUser` retrieves account information.
- `Enable-ADAccount` changes an account from disabled to enabled.
- `Unlock-ADAccount` resolves a lockout rather than a disabled state.
- `Search-ADAccount` can identify accounts matching specific conditions.
