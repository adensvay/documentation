# INC0042417 — User Unable to Sign Into Workstation

**Environment:** Windows Server 2022 / Active Directory  
**User:** Kevin Nguyen (`knguyen`)  
**Department:** Sales  
**Workstation:** `COMP01`  
**Priority:** P3 — Normal  
**Status:** Resolved

---

## Ticket Description

User reported being unable to sign into their assigned workstation despite being able to authenticate normally the previous day.

The user had already restarted the workstation multiple times before contacting IT.

## Initial Response

Acknowledged the incident, moved the ticket from **New → Active**, requested the user's employee ID for verification, and asked for the exact error being displayed during authentication.

---

## Investigation

### 1. Reviewed User Account in Active Directory

Opened Kevin Nguyen's account in **Active Directory Users and Computers (ADUC)** and reviewed the account configuration.

Under:

`User Properties → Account → Log On To...`

the account was configured with the following workstation restriction:

`DC1`

This was unexpected because Kevin is a Sales employee assigned to:

`COMP01`

A standard Sales user should not be authenticating interactively against the domain controller.

### 2. Corrected Workstation Authorization

Changed the permitted workstation from:

`DC1`

to:

`COMP01`

This restored the intended workstation authorization for Kevin's account.
