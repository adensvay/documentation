
# Windows Desktop Support Lab

## Overview

This project extends my hybrid Microsoft enterprise homelab with practical desktop support and workstation administration exercises.

The goal is to develop hands-on experience with Windows deployment, hardware and peripheral troubleshooting, network printing, and remote administration.

These exercises complement my previous experience supporting classroom technology at UC Santa Cruz ITS and help strengthen my traditional IT helpdesk and endpoint support skills.

## Lab Environment

- **Virtualization:** VMware Workstation
- **Operating Systems:** Windows 11, Windows Server 2022, Ubuntu Server
- **Identity Management:** Active Directory, Microsoft Entra ID
- **Networking:** TCP/IP, DNS, DHCP
- **Administration:** PowerShell, Remote Desktop Protocol (RDP), SSH
- **Hardware:** Physical network printer and workstation peripherals

## Documentation

Each completed exercise will include:

- Objective and environment
- Configuration or reported issue
- Tools and troubleshooting commands
- Resolution and verification
- Key takeaways

## Learning Objectives

By completing these exercises, I aim to:

- Develop confidence in common L1/L2 desktop support workflows.
- Improve Windows workstation troubleshooting and diagnostic skills.
- Gain hands-on experience with OS installation and workstation deployment.
- Understand network printing, printer drivers, and Windows print services.
- Configure and troubleshoot remote administration using RDP and SSH.
- Practice hardware, peripheral, and device driver troubleshooting.
- Document repeatable troubleshooting and resolution procedures.

## Scope

All exercises are performed in a personal homelab environment unless otherwise specified.

The project focuses on practical desktop support fundamentals rather than production-scale enterprise deployment.

As exercises are completed, individual Markdown documentation files will be added with configuration details, troubleshooting steps, screenshots, and verification results.
